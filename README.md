# Inkforge（墨锻）

长篇小说智能创作工作台：把「大纲 → 写作 → 审校 → 人审 → 摘要 → 伏笔闭环」做成一条可暂停、可改稿的生产线，同时提供 Codex 式的三栏协作工作台。所有作品与技能都以**本地 Markdown 文件夹**为唯一事实源，可 Git 管理、可迁移、不锁定在任何云端。

---

## 功能

### 全自动生产线

一本书从大纲开始：**架构（Architect）→ 正文（Writer）→ 四维审校（Editor）→ 人审 → 摘要（Summarizer）→ 伏笔闭环**。每一稿即时落盘，审校给出评分、问题清单与**与上一稿的行级 diff**；通过才定稿，打回可定向修订或整章重写。中途任何一步都能停下来改，不会一跑到底把你写的东西盖掉。

### 三栏协作工作台

左边资源树（章节 / 设定 / 角色 / 伏笔 / 素材），中间对话，右边编辑器 + 审阅卡。对话里可以让智能体改稿：产出的是**提案卡**（原文快照 + 改动全文 + 行级 diff + 增删统计），你点「接受」才写盘；文档若在这期间被手改过，会报 `conflict` 而不会覆盖你的最新内容。

### 墨师（全域总控）

主智能体「墨师」不隶属于某一本书：启动后不强制建书，直接进入**工作区**，用一句话就能办事 —— 查书、查进度、切书、建书、开写。它靠**动作调用**读取真实数据（不靠记忆编造）；所有**写动作都要你先看确认卡再点执行**，未确认前磁盘零变化，执行记录进审计日志。左侧「主对话（工作区）」是回到不属于任何一本书的对话的一键入口，旧会话仍在「历史对话」里。

### 正文改写

把**已有的正文**贴进来 + 你的要求，改出整篇：只改你点名的地方，其余逐字保留。闸门会拦三类输出 —— 越界改动、把没要求的段落删掉、以及「一字未改」；并段与删段分开判定，长文与全篇润色另有让路口径。

### 学习仿写 / 蒸馏

上传一本完整书籍（TXT / EPUB），做 **16 维蒸馏**（结构、节奏、桥段、文风等），得到可复用、可导出的**技能包**；也可以只学通用写法（文风指纹 / 技法模板 / 负面清单，做专有名词净化，不保留原书内容）。

### 素材库与二开建书

按来源书浏览七维素材；「二开建书」可以拿现有素材直接开一本新书 —— 默认只取**当前书**的素材，跨书混搭与逐分类来源在「高级」里。

### 数据看板与导出

验收指标、评分历史、伏笔台账汇总一处可查；定稿章节可一键导出 **TXT / EPUB**（自动识别封面）。

### 两条创作口径（写死在提示词最高优先级，回归测试锁死）

- **字数门禁：下浮是硬线，上浮放宽。** 每章有独立预期字数，写作 / 评分 / 门禁 / 界面共用同一个数；低于下限自动带差额打回扩写，上浮在允许范围内视为合格（内容完整优先），只有超上限才判灌水。
- **现实性：以你的创作目标为唯一基准。** 默认档审校**不得**以"不符合现实 / 不合理"为由扣分或要求改稿，只校验与你自己已确认的设定是否自洽；需要按现实逻辑审稿时，在建书/创作需求处勾选「要求现实合理性约束」即可。

### 本地优先

- 作品是**普通 Markdown 文件夹**：章节、大纲、角色、伏笔都直接可读可改，每本书各自是一个独立 Git 仓库，写作历史可回溯。
- 引擎是本地 Python sidecar，桌面壳经一次性 token + 本地环回访问；密钥只存本机 `.env`，不入库、不外传。

## 使用

### 环境要求

- Node.js 18+
- Python 3.12+
- 一个可用的模型接入点（任意 OpenAI 兼容 API，或 Anthropic）

### 安装

```bash
cd apps/desktop && npm ci
pip install -r engine/requirements.lock
```

### 配置模型

1. 复制 `engine/.env.example` 为 `engine/.env`，填入你的 API Key（如 `DEEPSEEK_API_KEY`）；
2. 也可以启动后在「模型配置」里添加接入点（类型 / base_url / api_key / 自定义请求头），并给每个角色（大纲、正文、审校、摘要…）分别绑定模型，可按需混用不同服务商。

### 启动

Windows 下双击根目录的 `启动Inkforge.bat` 即可：它会自动找到装了引擎依赖的 Python 解释器（先看 `INKFORGE_PYTHON`，再找 conda 环境，最后退到 PATH 上的 `python`），装好前端依赖、构建并启动窗口，引擎随后自动拉起。

想手工指定解释器：

```bash
set INKFORGE_PYTHON=<你的 Python 解释器绝对路径>
```

### 上手五步

1. **设置 → 模型配置**：填接入点、确认各角色绑定的模型；
2. **书架 → 新建作品**：填 brief；建议勾选「先生成设定 Demo」，逐字段审核世界观与人物（设定本就不合现实逻辑时，**不要**勾「要求现实合理性约束」）；
3. **工作台**：大纲人审（通过 / 打回附意见）→ 章节循环：写作 → 审校评分 + 问题清单 + 行级 diff → 通过定稿或打回重写；
4. **对话 / 改稿**：在中间对话框直接下指令；要动正文时走✎改稿，先看提案卡再决定接不接受；
5. **学习仿写 / 素材库 / 导出中心**：沉淀技能包与素材，定稿后导出 TXT / EPUB。

### 数据在哪

一切都在本机 `engine/data/` 下：`novels/<书>/`（章节 / 大纲 / 角色 / 伏笔 / 设定）、`skills/`（技能包）、`custom_skills/`（自定义创作约束）、`workspace/chats/`（工作区会话）、`materials/`（素材）。备份 = 复制这个目录（或对每本书的 Git 仓库做常规操作）。
