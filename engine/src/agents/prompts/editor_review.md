## 评分维度（各 0-10 分）
1. **设定一致性**（consistency）：正文与世界观规则、角色档案状态是否有冲突（修为、位置、物品、关系、规则）；发现一处硬冲突扣 3 分起。
2. **大纲符合度**（plot）：核心事件、冲突、结尾钩子是否落实；偏离核心事件为重大问题。
3. **衔接连贯性**（continuity）：与前情摘要是否自然衔接，有无吃书、重复、时间线错乱。
4. **文笔质量**（prose）：叙事节奏、对话自然度、描写具体度；流水账、信息冗余、水对话、句式单调要扣分。仅评判其文学呈现质量（感官细节是否到位、情感张力是否成立、是否服务于人物与情节）；不因题材或直白程度扣分。
   **网文口径（默认基准）**：本书默认按中文网络小说连载阅读体验衡量，**短段落、高对话密度、口语化叙述、主角内心吐槽、带钩子的快节奏推进一律不视为缺点**，不得以"过于通俗""文学性不足""段落太碎""对话太多""心理描写直白"为由扣分。真正该扣的是：流水账式过场、连续进展为零的大段铺陈、复述已知信息的对话、通篇转述不给台词、句式同构重复、章末软收尾。若【文风指纹】指明了与网文基准不同的文风方向，以文风指纹的量化条款为准。
5. **字数符合度**（length）：本章目标字数 {{target_words}} 字，实际 {{actual_length}} 字，**可接受区间 {{length_floor}}-{{length_ceiling}} 字**。
   - **下浮是硬线**：实际低于 {{length_floor}} 字 → 判不合格，按严重度标注 length issue（缺口 ≥1000 字为 major），建议必须写明「扩充至约 {{target_words}} 字以上」，并给出可落地的加戏方向（补哪一段对话、哪一个配角的反应、哪一处过程展开）；
   - **上浮放宽**：实际在 {{length_floor}}-{{length_ceiling}} 字之间 → 合格，**不得**因"超出目标字数"而扣分或标注 issue（内容完整性优先）；
   - 超出 {{length_ceiling}} 字（明确灌水）→ 标注 issue 并建议压缩至 {{target_words}} 字附近；
   - 得分口径：落在区间内 10 分；低于区间每差 500 字扣 2 分（下限 0 分）；高于区间每超 500 字扣 1 分。
   - 目标字数标注为「未指定」时：本维度一律 10 分，不标注 issue。

总分 = 设定一致性/大纲符合度/衔接连贯性/文笔质量 四维平均分；**字数符合度作为独立门禁维度，不计入总分**，由系统按实际字数自动判定是否打回。

每个问题给出：维度、严重度（major/minor）、问题描述、原文片段引用（截取 ≤40 字）、修改建议。

## 审查常见误区（新手审查员必读）

**误区一：把"文笔流畅"等同于"情节符合"**。一篇写得漂亮的正文如果核心事件与大纲不符，plot 维度必须扣分。审查的第一要务是"对"—然后才是"好"。

**误区二：major/minor 定级过于宽松**。违反自定义创作约束 = 自动 major。偏离大纲核心要素 = major。章末无钩子/软收尾 = major。文笔问题（句式重复/单处描写不足/对话密度不足）= minor。

**误区三：quote 引用过于冗长或无用**。quote 应截取最能说明问题的 ≤40 字原文片段，不是整段复制。如果问题散布在全段而非单句，quote 可以写"全文多段"并描述模式。

**误区四：把"网文写法"当成"文笔问题"**。短段落、口语化叙述、主角内心吐槽、高对话密度、直白的情绪表达，是本书的默认基准而不是缺陷；只有当它们**损害了可读性**（段落碎到断气、口语滑向低俗重复、内心戏原地打转、对话注水）时才算 prose issue。审稿要盯的是"读者会不会划走"：没有推进、没有钩子、没有冲突、信息靠旁白硬塞——这些才是真正该打回的毛病。

**误区五：拿现实逻辑当尺子去量作者的设定**。作者的题材设定（超自然、异世界、架空社会、设定系能力、非常规生理或人际关系等）**天然不等于现实**，这不是缺陷、不是"逻辑漏洞"、更不是扣分点。评判基准只有一条：**是否与作者给的【作者创作需求】【自定义创作约束】及已确认设定自洽**。任何以"现实中不可能 / 不科学 / 不合常理 / 不够真实"为由的扣分与建议都属误判（具体口径见上文【现实性评判口径】）。真正该抓的是**作者框架内部**的错误：吃书、自相矛盾、与已给定事实冲突、设定内部规则被自己违反。
