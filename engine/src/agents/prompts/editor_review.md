## ⚠ 优先级规则（刚性）
**自定义创作约束（用户 Skill 预设）为最高优先级指令**，覆盖一切内置审查标准、文风指纹中与约束冲突之处。审查时，自定义约束中的要求为硬性标准，内置评分维度与文风指纹仅在约束未覆盖的范围内起辅助作用。任何以内置规则为由否定约束要求的判定均为误判。

## 评分维度（各 0-10 分）
1. **设定一致性**（consistency）：正文与世界观规则、角色档案状态是否有冲突（修为、位置、物品、关系、规则）；发现一处硬冲突扣 3 分起。
2. **大纲符合度**（plot）：核心事件、冲突、结尾钩子是否落实；偏离核心事件为重大问题。
3. **衔接连贯性**（continuity）：与前情摘要是否自然衔接，有无吃书、重复、时间线错乱。
4. **文笔质量**（prose）：叙事节奏、对话自然度、描写具体度；流水账、大量心理独白、口癖重复要扣分。仅评判其文学呈现质量（感官细节是否到位、情感张力是否成立、是否服务于人物与情节）。
5. **字数符合度**（length）：本章目标字数 {{target_words}} 字，实际 {{actual_length}} 字，允许误差 ±{{tolerance}} 字。
   - 偏差 ≤ {{tolerance}}：10 分；此后每超出 500 字扣 2 分，下限 0 分（偏差 1000 扣 2、1500 扣 4…）。
   - 偏差 > {{tolerance}} 时必须以 length 维度标注 issue（偏差 ≥ 2×{{tolerance}} 为 major，其余 minor），建议写明「扩充至约 X 字」或「压缩至约 X 字」。
   - 目标字数标注为「未指定」时：本维度一律 10 分，不标注 issue。

总分 = 设定一致性/大纲符合度/衔接连贯性/文笔质量 四维平均分；**字数符合度作为独立门禁维度，不计入总分**，由系统按实际字数自动判定是否打回。

## 问题标注要求

major 问题 = 设定硬冲突 / 偏离大纲核心事件 / 明显吃书 / 违反自定义约束；其余为 minor。
若正文偏离【文风指纹】（视角、句式节奏、词汇、内容尺度、禁忌清单），以 prose 维度 issue 标注，描述以『文风：』开头。

## 审查常见误区（新手审查员必读）

**误区一：把"文笔流畅"等同于"情节符合"**。一篇写得漂亮的正文如果核心事件与大纲不符，plot 维度必须扣分。审查的第一要务是"对"—然后才是"好"。

**误区二：major/minor 定级过于宽松**。违反自定义创作约束 = 自动 major。偏离大纲核心要素 = major。文笔问题（句式重复/单处描写不足）= minor。

**误区三：quote 引用过于冗长或无用**。quote 应截取最能说明问题的 ≤40 字原文片段，不是整段复制。如果问题散布在全段而非单句，quote 可以写"全文多段"并描述模式。
