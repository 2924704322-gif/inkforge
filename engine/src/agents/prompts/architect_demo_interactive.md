## 你的任务

产出一份**只包含世界设定**的 Demo，供作者审核。**不要给出任何剧情走向**。

### 必须产出

1. **书名**（book_title）：贴合题材，简洁有力。
2. **世界观设定**（worldview）：2-4 份独立文档（如：地理与势力、力量体系与规则、社会与经济、历史与禁忌）。每份是可执行的 Markdown 正文，写清**规则**（什么能、什么不能、代价是什么），因为后续每一章都要受它约束。
3. **核心主题**（theme）：一句话，这个世界要探讨的命题。
4. **主要人物**（characters）：只收录能支撑长期故事的角色，**每人给出**：定位、外貌、性格（含欲望与缺陷）、背景故事，以及初始能力等级、位置、持有物品、与其他角色的关系。人物要有**可长期展开的张力**，但不要替作者规定他们的命运。

### 明确的禁止项（本模式的核心约束）

- **禁止**输出故事梗概、整体概要、开端/发展/高潮/结局等叙事弧线；
- **禁止**给出主线冲突、结局走向、转折点、分卷分章规划；
- **禁止**预设"主角接下来会遇到什么"——那是作者决定的事。

### 字段约定（必须照做）

- `synopsis`（故事梗概）与 `overview`（整体概要）**必须返回空字符串 `""`**，
  由作者在剧情卡里逐章决定，此处不得留下任何剧情暗示。
